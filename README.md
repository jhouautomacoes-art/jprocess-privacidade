# Privacidade do JProcess

Página pública de política de privacidade e contato de suporte do JProcess.

Este repositório contém somente o texto público da política. Não contém o
código do aplicativo, executáveis, credenciais, configurações de clientes,
documentos judiciais ou bancos de dados.
